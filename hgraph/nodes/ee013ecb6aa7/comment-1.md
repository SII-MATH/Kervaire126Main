Scope of the related interface family `synthetic-homotopy-separation`. This note does not assert equivalence with a broader paper statement or mark any proof complete.


- **mathematical_purpose**: 同一固定 synthetic 塔在所选对象实际有限 λⁿ 商上的同伦滤过分离性；不再断言未截断普通球/ν 对象的全称零结论。

- **scope**: XModLambdaN (X.obj model.nu model.auxiliary) n for X : SyntheticObject and n : ℕ; the same actual lambda cofiber and synthetic tower

- **not_asserted**: Separation for every object of SyntheticSpectrum

- **not_asserted**: A uniform or finite filtration bound

- **not_asserted**: Classical finite-map odd-torsion separation

- **not_asserted**: An automatic consequence of canonical E-infinity identification

- **not_asserted**: Untruncated sphere or arbitrary nu-object Hausdorffness

- **not_asserted**: Vanishing of odd-primary infinite-filtration classes on the ordinary sphere

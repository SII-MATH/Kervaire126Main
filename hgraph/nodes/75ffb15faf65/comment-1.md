Source verification (2026-10-18): Source adaptation checked. Put a=t-w. In the polynomial-lambda spectral sequence of BHS Theorem A.8, an incoming classical d_i has a source label with lambda exponent a-i+1. All incoming differentials contributing before page r have 2<=i<=r-1, so they all occur once a>=r-2. Outgoing cycles agree under localization. Thus the localization map is an isomorphism for a>=r-2, including the boundary case; this is a derived range, not the literal range printed in Corollary A.9(4). The inverse, E2 normalization, lambda square and differential square are obtained from this same localization map, rather than from unrelated choices of isomorphism. Write the BHS coordinates as (s,k,omega) and the project coordinates as (s,t,w). The translation is k=t-s and omega=w-(t-s); tau is renamed lambda. Hence s-omega=t-w, and the BHS differential degree (r,-1,1) becomes (r,r-1,0). This verifies the mathematical source and its stated regrading, not the outstanding Lean comparison with the fixed project model. Existing Lean proof and transitive-dependency status must remain unchanged. Spectral-sequence page and E-infinity subquotient statements here do not assert convergence to untruncated homotopy groups; BHS Convention A.5 allows an arbitrary spectrum for Theorem A.8 and Corollaries A.9/A.11.

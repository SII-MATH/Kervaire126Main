Scope of the related interface family `canonical-convergence-detection`. This note does not assert equivalence with a broader paper statement or mark any proof complete.


- **mathematical_purpose**: 实际同伦群的滤过由塔投影range定义；E∞识别在同一lift的cofiber像上规范化。

- **constraints**: No independently chosen filtration is accepted.

- **constraints**: The same lift supplies both the E1 cofiber class and the projected homotopy class.

- **constraints**: Synthetic canonical convergence retains the weightHomotopyMap filtration-membership equivalence.

- **constraints**: Convergence is requested on individual selected objects, not all ambient synthetic spectra.

- **constraints**: Zero detection raises filtration; it never directly asserts the homotopy class is zero.

- **constraints**: Nonzero detection requires a nonzero common E-infinity representative, not merely a nonzero E2 label.

- **roles**: data

- **roles**: structural-law

- **roles**: derived-theorem

The bound Lean degeneration interface quantifies every integer N; since DegeneratesAt asks for every differential r>=N, the N<2 portion additionally requires a below-first-page normalization for the actual synthetic family. BHS Theorem A.8 does not provide that project-specific portion. The canonical classical construction does set r<2 differentials to zero in Internal/Source/AdamsSequence.lean:207, but no matching synthetic-family normalization was found in this research. This is an unverified scope endpoint, not a verified counterexample or authorization to edit an interface. Write the BHS coordinates as (s,k,omega) and the project coordinates as (s,t,w). The translation is k=t-s and omega=w-(t-s); tau is renamed lambda. Hence s-omega=t-w, and the BHS differential degree (r,-1,1) becomes (r,r-1,0). This verifies the mathematical source and its stated regrading, not the outstanding Lean comparison with the fixed project model. Existing Lean proof and transitive-dependency status must remain unchanged.

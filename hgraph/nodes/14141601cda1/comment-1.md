Scope of the related interface family `obligation-adams-boundedness`. This note does not assert equivalence with a broader paper statement or mark any proof complete.


- **mathematical_purpose**: For finite, RationallyAcyclic and HomotopyTwoLocal X, every fixed actual pi_i has F^s=bottom for all sufficiently large s in the same P. Rational acyclicity means all homotopy elements are torsion; two-locality means odd scalar multiplication is bijective.

- **constraints**: For finite, RationallyAcyclic and HomotopyTwoLocal X, every fixed actual pi_i has F^s=bottom for all sufficiently large s in the same P. Rational acyclicity means all homotopy elements are torsion; two-locality means odd scalar multiplication is bijective.

- **constraints**: Replace True by explicit finite/rationally-acyclic/two-local hypotheses. Replace exclusion of all elements, including zero, by F^s=bottom; excludes_nonzero and filtration_contains_zero provide correct consumer forms. Two-locality excludes unlocalized odd torsion of infinite mod-two filtration.

# 接口调整人审目录

本轮 a48 迁移的三个上游补证 session 共用此目录；此位置由任务 prompt 指定。准备提示词时未启动数学任务，也没有预先批准任何接口调整。

报告位置为 `<责任模块>/<唯一 issue-id>/report.md`；必要证据放同目录。每份报告由未参与该候选实现/发现的独立 `kip_interface_reporter` 核验并撰写。协调者给人类报告绝对路径；不要共写全局报告索引。

报告包含原接口完整声明、背景与问题成因、真实前提和固定对象核对、证据与复现及依赖审计、保留接口的备选办法、精确调整方案、下游与责任影响、阻塞和可继续项。模板安装在 `~/.agents/skills/kip-upstream-session/assets/interface-review-template.md`。

初始状态为 `pending-human-review`，`human_decision: null`。仅在人类明确批准具体报告、方案及范围后才能实施；记录真实决定及出处。等待、沉默或 agent 建议都不构成批准。报告排队时只暂停真正依赖该接口的目标，其余补证继续。

这个共享目录是有意集中存放的报告区域；三个 session 的数学源码、全局待补清单、Git 分支和可写 Lake 状态仍在各自独立工作树中，不回写共享主工作区。报告中的源码位置须注明所属工作树、基线提交和文件哈希，避免混淆不同分支。

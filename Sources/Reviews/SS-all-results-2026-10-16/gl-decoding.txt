## 1. 实际需要的版本，而不是 Main 的固定实例

SS 的 `Syn` 需要的是**带 cutoff 的 synthetic 交换方框 GL**；`SynCs`／`SynCsIn` 还需要**有限关系向完整 ν／经典 ESS 的推广与解码**。它们不能由 Main 的 `(n,m,l,s,t)=(3,0,0,8,134)` 固定零层接口替代。

`SetCwDiffSynthetic` (`category.cpp:476–540`) 的输入与输出字典为：

- 输入 `d_b(x)=z`，源滤过 `s`。
- 第一次 `GetSynImage` 给 `y`，滤过 `s+M`。
- 第二次给 `w`，滤过 `s+b+Lout`。
- 写入普通 Adams 微分 `d_q(y)=w`，`q=b+Lout−M`。
- 日志的 `k` 实际是 cutoff `κ=r_fx_tmp+(dfx_tmp.empty()?1:0)`，不是王稿的数学 λ-level。
- 第一调用是 `level_x=10000−b`，第二调用是 `level_x=b`。它们是 Adams 状态编码，不是 λ-level。

两个入口不同：`SetCwDiffGlobal:468` 限 `b≤6`；`DeduceDiffBySynthetic` (`deduce.cpp:247–275`) 遍历所有当前已知 outgoing 微分，没有这一上限。

## 2. 程序实际排的是窗口 crossing

`category.cpp:496`：原 Adams 微分能排除 crossing 时，首条 extension 不必再全排；否则首调用 `cross_min=0` 要求它排 crossing。代码符合“原微分或首 extension 无 crossing”的 OR。

`497–503`：读取 `y` 已知可存活页，并用 `GetCrossR` 的更早潜在 crossing cutoff 截断，得到 `κ`。

`512–515`：第二次调用只排命中目标滤过 `≥s+M+κ` 的 crossing，并且要求 `q≥κ`。这比“底边全部无 crossing”弱，正是一般 cutoff 方框定理的形状。王稿 `sec6:196–198` 说可由一般方框定理推广并留读者完成；不能把其两个印出的简版 GL 直接当作代码所用完整版本。

`GetCrossR` (`ss.cpp:258–285`) 对高源偏移 `a=1,…,Er−2` 检查最早可能普通 outgoing 微分长度 `ρ`，返回 `min(a+ρ)`。超出已知范围时保守使用最早长度 2。其正确性以前提为当前 staircase 和空组／消失线数据正确，不能把 `hasCross=true` 读成确实存在 crossing。

日志代理这轮读取全部 `573` 条 `Syn` 后，`q≥κ` 对 `573/573` 成立；直接邻接 grey 父行的 `464` 条，加上唯一兼容恢复的 `35` 条，共 `499` 条普通长度界全部成立。余下 `74` 条中，19 条全部候选都满足界，55 条候选混合，未判。原生 E2 复核的 499 对调用中，包含 36 对 M0/M0 和 48 对 D候选/M1，确实不只用自然性或非递归分支。D候选仅是 raw E2 像坐标吻合，不认证历史 level_fx 提前 return 测试。证据 `/tmp/SS-All-Results-Audit-20261016/logs-GL-branch-summary.json`。

## 3. 一个精确、足够且适配程序的 GL statement

令 `Q_N(V)=νV/λ^N`，`e=e(f)`，所有移位按实际规范化 f 吸收。取整数：

- `b≥2`, `M,Lout≥e`, `q=b+Lout−M`；
- `K≥0`, `N≥1`, `A=M−e+K`；
- `0≤K<N`, `0≤A<N`, `D=b−N−1+K≥0`；
- `1≤κ≤q`。

在同一个真实交换方框

```
Q_N(X)  -- f_N -->  Q_N(Y)
  | δ_X                | δ_Y
shifted νX -- f --> shifted νY
```

中，具有以下三条**实际 ESS 关系**（包括源定义域、边界商及较短 ESS 像不定性）：

1. `δ_X : λ^K x ↦ λ^D z`，编码 `d_b(x)=z`；
2. `f_N : λ^K x ↦ λ^A y`；
3. 完整 ν 中的 `f : λ^D z ↦ λ^(D+Lout−e) w`。

另要求：

- 第 1、2 条至少一条无 crossing；
- 第 3 条没有命中 Adams 滤过 `≥s+M+κ` 的 crossing；
- 右边 δ_Y 上 `λ^A y` 至 `κ−1` 的零关系及其无 crossing 成立。

则一般 cutoff 方框定理给

`d_q^(δ_Y)(λ^A y)=λ^(A+q−N−1) w`。

因 `A<N`，该 δ 标签在可见范围，由正确 δ 编码得到普通 `d_q(y)=w`。右侧指数由 `A+q−N−1=D+Lout−e` 恰好配平。这里没有取消 λ，也没有反演有限商。

这已经是以 ESS 为语言的清晰充分版本；不必再额外要求底边预先挑出的具体见证等于 `δ_X` 作用于首个见证的值。一般方框的无 crossing 同步论证负责挑选相容代表。**但第 3 条必须真正在完整 ν 的同一标签上成立，有限商中同名标签的一条关系不能自动替代它。**

适用范围 `0≤A<N≤b+K−1` 存在的必要充分算术条件为 `M≤b−2+e`。王稿正 level GL 除原 `M≤n−2+e` 外，还需实际 `M−e+K<n−1`；原条件只保证 K=0 时可见。王稿 sec6:172 把 δ 左边仍写成 x，顶边却写 λ^k x，也须同步改成乘 λ 后的 δ 关系。不能以日志 cutoff κ 代替 K。

### 两次直接 E2 像的安全分支

若两调用都在 `category.cpp:563–564` 返回，则 `y=f_*x`, `w=f_*z`, `M=Lout=a_f`，`q=b`。普通 Adams 自然性直接给 `d_b(y)=w`，无须 MH2 或 GL。即使 a_f 与 e(f) 不同，也可用这一直接证明。

只有首条为直接 E2 像、底条为隐藏像的混合路径，不能用上述双直接证明；须分别提供真实方框证书，或采用重新规范化 lift 的独立论证。不能把所有 return 0 都归入同一 MH2 statement。

## 4. 本轮新消除的一部分‘缺条件’：原生 May 商自动满足范围

以下推导以前提为：该隐藏调用已被正确的强 MH2 版本认证（递归时允许先把源换为保持原微分的同类代表）。它不是由未经证明的算法正确性直接推出，也不调用 GL，故可作为 MH2→GL 的非循环推导。

记首次隐藏求像使用：内部微分长度 R，前一箭头 h 的 extension 长度 L，下一箭头 g 的实际 E2 滤过 `a_g`。原生 May 商与 level 为

`R=M+a_g+L`, `N=R`, `K=L−e(h)`。

记 `m1=a_g−e(g)≥0`，`e(f)+e(g)+e(h)=1`，则

`A=M−e(f)+K=N−1−m1<N`。

因此**保留强 May 商后，顶边目标天然可见**；王稿弱投影商丢失目标信息并不说明强商也丢失。

核心 MH2 还给 source cycle

`x1∈Z_Q`, `Q=M+a_g+e(h)`。

若 `x1−x∈Z_b`，则 `d_b(x1)=z≠0`。故 `Q≤b−1`，进而

`M≤b−1−a_g−e(h)≤b−2+e(f)`，

及 `N≤b+K−1`。于是最重要的 GL 长度上界和合法顶边商可以由**核心 source-cycle 结论 + 代表 coset 同步**推出，不必新增独立数学前提。

原始代码的较弱数值检查也可部分证明该界：

- 直接 h 前像分支 `621–622` 给 `R<b`，结合 `M=R−a_h−a_g` 足够。
- 递归分支 `581–582` 单独只给 `M≤b−1−a_g`，在 `e(h)=1,a_g=0` 时差 1。上述强 MH2 source-cycle 正好消除临界，但尚须证明递归前提及 coset 同步，不能仅凭 return 0 宣称。

### 原生商还缩小了右边 δ crossing 窗口

可在同一 N 内把首条关系再乘 `λ^Δ`，其中 `0≤Δ≤m1`，仍可见。相应：

- 右边源层为 `A+Δ`；
- 底边所需层为 `D+Δ`, `D=b−Q−1`；
- 右边任何非零 higher-source δ crossing 的源偏移 a 必须 `A+Δ+a<N`，所以 `1≤a≤m1−Δ`。

输入清单给实际三角总 E2 滤过为 1 或 2，即总 excess `δ_f+δ_g+δ_h≤1`。隐藏调用有 `M≥e(f)+1`，故

`M−a_f≥1−δ_f≥δ_g=m1`。

代码 `GetCrossR(y, Er=M−a_f+2)` 扫 `1,…,M−a_f`，因而覆盖上述右 δ 窗口。这推翻了“正 level 一定导致代码右窗口不够”的泛泛说法。还需以正确有限标签／δ 编码证明每个 essential δ crossing 对应被扫描的普通 outgoing 微分；这里给出的是精确可证明的范围归约，不冒充全算法形式化。

### 仍需的底边层数兼容

若二次调用仅能在完整 ν 的层 K2 给底边，而要用上述顶边，则需能升到 `D+Δ`；一个清晰充分条件为

`K2≤D+Δ`，`0≤Δ≤m1`。

因此允许调整的最大底边层是

`D+m1=b−M+e(f)−2`。

实际必须重建二次调用的完整 ν 关系及 level，不能把两次 return 0 直接宣布为共同层。升层后的 crossing 也应针对实际标签核对，不能未经证明沿用旧 0 层公式。

## 5. 永久源真的有状态依据；目标永久性仍是输出

不能仅看到 `deduce.cpp:296` 硬传 LEVEL_PERM 就说源码没有源永久依据：

- `ss.cpp:331–340` 在 `r==R_PERM` 时将 Adams 永久源加入 cofiber ESS。
- `cofseq.cpp:812–825` 的 SyncCofseq 只把 ASS `level==9000` 的类加入 ESS。
- `cofseq.cpp:244–283` 持续约掉 Adams 边界。
- 已保存 cofiber 表也作为输入加载 (`loadsave.cpp:485–490`)，故初始表满足同一状态不变式必须纳入输入审计。

在输入表和状态更新规则已正确认证的前提下，SynCs 的源永久性可从这些不变式证明。源永久性本身不是新假设。

但 `GetFirstIndexOfFixedLevels` (`ss.cpp:24–40`) 排除已固定非零 outgoing 源，仍保留未知未来微分的候选；这不是先验 Z∞。`deduce.cpp:301–303` 的 SynCsIn 正在写入目标永久性，不能反过来当输入。

此外 `GetSynImage` boundary/permanent 分支 `category.cpp:639–656` 的核唯一性及模边界方程是实质数学约束；不应说它只凭猜测求像。

## 6. 有限→完整→经典的两个精确充分版本

### 6.1 直接提升证书（干净但较强）

在强 Q_N 内有实际源代表 a_Q，检测 `λ^K x`，其 f 像检测 `λ^J y`，`0≤K,J<N`。若 a_Q 能提升到完整 νX，则完整 f 像在低层具有相同首项；有限与完整低层标签的单射比较推出 y 永久，最后反演 λ 得经典 f-ESS 关系。

提升障碍为 cofiber 长正合列中的 `∂(a_Q)=0`。这不要求预先 y 永久，因此非循环。但**这个特定 May 代表可提升不是必要条件**。

### 6.2 允许改动高滤过的更弱证书

设 A 是所有满足同一源首项、且 f_Q 像保留所需目标首项的有限代表的非空仿射族，写 `A=a0+V`。需要的条件只是

`A ∩ image(πνX→πQ_NX) ≠ ∅`，

等价于 `∂(a0)∈∂(V)`。

它允许用高滤过修正改变原 May 代表，强于仅知 x 永久，弱于固定 a0 必须提升。这是无须先验目标永久性的准确障碍表达。

还可用有限滤过修正证明这一仿射条件。取检测 x 的任意完整源 lift α∞，与 a0 的有限投影差为 δ∈F^{s+1}。只需在所有相关修正层 k≤目标滤过，保证二择一：

1. δ 的当前 grade 来自完整源的同层 grade，可用一个完整高滤过元素消去；或
2. f_Q(δ) 已在目标滤过再高一层，故不改变目标首项。

逐层修正后，所得完整源的有限像保留 y。完整→有限在保留层的单射性继而推出完整 f 像检测 y；由此先得到 y 永久，再得到经典输出。

这给出不依赖‘原 May 严格代表提升’的可证推广路线，不需先使用正在推导的 SynCsIn。

## 7. 代码的 kernel + crossing 能否证明上述修正条件？

有希望，但本轮尚未完成联合正确性证明；不应把‘没保存几何见证’直接判作缺少新数学假设。

修正二择一失败会给同一有限商中的 nonliftable-source 非零像，正是当前已修复 `FiniteExtensionNonliftableCrossing` 的几何形状。该条件位于 `KIP126/ProofTools/Language.lean:119`；其有限 stretching 证明在 `Stretching.lean`。它允许 `b=0`、长度零以及非 essential 但原始目标非零的方程，且是实际 ρ 的 graded 像条件，不是只看普通 x′ 属于哪个 Z。

程序 `category.cpp:673–707` 的 sweep 对永久源会考虑所有 `level>=9000` 的未知／已知未来 outgoing 类；Adams 边界本身永久，跳过它们不自动造成问题。但仍需逐项证明：

- 逐个 staircase 基底递归求像足以控制所有线性组合与相消后产生的像。
- 当真实 nonliftable crossing 存在时，递归 finder 必返回它或拒绝主调用；不能只证明 finder 每次成功都是正确关系。
- `error12` (`621–622`, `704–705`) 被忽略时，确实不会掩盖相关同商 nonliftable 非零像。
- 主源 coset 改动、目标模边界与较短 ESS 像同步；尤其 boundary 源分支 level=b 时，`<level` 前段对应 B_(b−1)，不是 B_b（本文 B_b 包含 d_b 的像）。outgoing 源分支 level=10000−b 时，相同前段则是 Z_b，应区分。
- GL 二次 boundary 源调用的 sweep 跳过 level<b 的较短 Adams 边界。这些标签在完整 ν 中是否为零，应按实际层 D+Δ+a 与边界阶 c 比较（c≤D+Δ+a+1 才自动消失），不能单以 c<b 断言无关。所需源 coset／δ 代表同步必须补上此情形。右 δ 窗口覆盖的证明不等于底边 sweep 全部正确。
- 严格 sweep 端点 `s1<sy−a_f` 与只排某些候选之间的剩余情况由 kernel uniqueness 处理：端点是直接 E2 像，`g_*f_*=0` 把它送入候选核。**若该像属于候选空间**，核唯一性可迫其为允许边界；这支持联合证明，不能孤立把端点认作漏洞。但候选空间闭包与所有可能修正像的包含仍需证明。
- 若使用已形式化有限 stretching，须注意它当前还假设目标有后页 cycle 资格，且只输出有限后页关系；不能直接当作‘自动产生目标永久性及完整 ν 关系’。本节的无先验目标版本需要另行证明，纸面修正论证见 6.2。

因此，当前剩余的是一组**程序分支正确性／完备性引理**，其中一些可能完全由现有状态和线性代数推出；不能一律包装成作者必须额外加的数学假设，也不能尚未证明就宣称全表已覆盖。

## 8. 与王稿覆盖关系及最终边界

| 所需环节 | 王稿当前覆盖情况 | 本轮结论 |
|---|---|---|
| h,g 为 level 0 的核心 MH2，输出保留 level，强 May 商 | 方向成立，需保留强商和同一构造 | 可作算法证书基础，不限 Main 固定实例 |

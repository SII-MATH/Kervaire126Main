## 1. 统一参数，不把程序 level 当作数学 level

重命名当前三角为 `X --f--> Y --g--> Z --h--> ΣX`。程序当前 map=f、next=g、prev=h。令 `d_f,d_g,d_h` 为实际 E2 映射的 AF 次数，`e_f,e_g,e_h∈{0,1}` 且和为 1；通常 d=e，但 θ4、θ5、σ²、2σ 的检测映射 d=2,e=1。

令输入 x 滤过 `s_x`，中间 `barx=xtop` 滤过 `s_0`，已知非零 Adams 微分 `d_a barx=bary`，最终输出 y 滤过 `s_y`。则

```
l=s_x-s_0, m=d_g, n=s_y-s_x=a-l-d_g,
k=l-e_h, m1=d_g-e_g, n1=n-e_f,
r=a=n+m+l, r'=a-m1=n1+k+1,
Q=a-k=n+m+e_h.
```

程序 `level_x=10000-b`（d_b 源）、`level_x=b`（d_b 边界）、`level_x=9000`（永久部分）均是 staircase 状态编码，不是 k。

**边界下标更正：** 论文 `AimPaper/main.tex:832` 定义 B_r 包含 d_r 的像。源码取 staircase 的 `level<a` 前段，故数学记作 B_(a−1)，不是旧报告的 B_a；以下均按论文这个含端点的约定。强 MH2 的源分母 B_(k+1)、目标分母 B_r' 则由 synthetic offset 公式得出，保持不变。

## 2. 可证明的核心 MH2，应保留强有限商结论

对上述三角、`n1≥1,m1,k≥0`，假定

1. `barx∈Z_(a−1)`, `bary∈Z∞`, `d_a barx=bary`；
2. `x∈Z_n1`, `y∈Z_(m1+1)`；
3. 第零数学层的 h 关系 `d_l^(h,E_r') barx=x`；
4. h 关系或该 Adams 微分在所需页无 crossing；
5. 第零数学层的 g 关系 `d_m^(g,E_(m1+2)) y=bary`。

则王稿核心的 May 论证给

```
x∈Z_Q,
d_n^(fhat_a)(λ^k x)=λ^(n1+k)y   in ν(-)/λ^a.
```

实际源标签是 `Z_Q/B_(k+1)`，实际目标是
`(Z_(m1+1)/B_r') / (短 fhat_a-ESS 边界)`。这里 ESS 等式包括短 ESS 边界不定性；不等于固定 E2 向量间严格同伦等式。

这个强版本经投影才给王稿字面 `d_n^(f,E_(Q+1),k)x=y`。当 k≥m1+1，投影后的目标层已越出截断；它可能只是零关系。支撑程序写具体 y 必须优先保留强商，不可从弱结论取消 λ。

## 3. D 与 M0：源码何时确实提供前提

### D：非零 E2 像直接返回，558–564

若 `z=f_E2(x)≠0` 且 `level(z)≥s_z−s_f_dinv_x`，返回 z。这是已给定 AF=d_f 的映射自然性路径，不是 MH2。仍以该 E2 映射确实对应所声明实际映射为外部数据前提。

### M0：f_E2(x)=0，599–624

用 E2 矩阵找 h_E2 前像 barx，故 `l=d_h,k=d_h−e_h`。目标解方程 `g_E2(y)=bary mod B_(a−1)`（631–673）。

当 d_h=e_h、d_g=e_g：k=m1=0。h 在最短允许长度，相关 crossing 范围为空；g 前提只需 y∈Z1，方程中的 B_(a−1) 差可吸收入 d_a 的目标代表。核心给真实第零层关系，覆盖 175 个配置方向。不是 175 条成功日志。

当 k=1,m1=0：核心能给带一层输出；还须认证 h 的实际有限商关系/无 crossing。原先只按 e_h 写的 crossing 范围未必为空。若另证选定 normalized h 实现具有全局 AF≥d_h，则所有更短 h-ESS 微分为零，可由这个更强的实现定理推出无 crossing；配置中的一个 E2 次数本身不自动提供这个实现定理。

当 k=0,m1=1：需 y∈Z2 以及 g 在 Q2 中的实际第零层关系。有限源分支枚举整个 E2 目标，并未显式筛选 Z2。求逆矩阵在 y 次数的单射，也不能单独推出 d2(y)=0；后者涉及另一双次数。不能因 bary 永久就沿 g 反推 y 永久/存活而不检查核。

## 4. M1：递归实际需要的是 source coset 版本

558–595：f_E2(x)=z≠0，但 z=d_c(v)，c 小于调用者允许阈值。令

```
barx=g_E2(v),
s_0=s_x+d_f−c+d_g,
l=c−d_f−d_g,
k=c−d_f−d_g−e_h,
n=a−c+d_f.
```

程序递归 `GetSynImage(prev,barx,level_barx,...,cross_min=0)`，把返回的 h-像记为 x1，然后检查 x1 与 x 同次数及其差属于 `span(level<level_x)`。

这一步不能称“固定 x 的有限商标签相等”。准确字典为：

| 外层输入 | line592 实际比较 | 足够用于什么 |
|---|---|---|
| d_b 的非零源 | x+x1∈Z_b（以当前已证 staircase 子空间为准） | d_b[x1]=d_b[x]，允许联合 GL 将源换成 x1 |
| d_b 的边界 | x+x1∈B_(b−1) | 同一个 d_b 目标 coset |
| 永久源 | x+x1∈B∞ | 同一个经典 E∞ 类，但仍非固定 synthetic 代表 |

**新收窄结论：有限源模 Z_b 本身并不是算法错误证据。** 线性谱序列中若 x1=x+z、z∈Z_b，则 x1∈Z_(b−1) 且 d_b x1=d_b x。故正确的整体命题应允许取源 coset `[x]∈Z_(b−1)/Z_b` 的代表；不必要求递归恢复原固定 E2 标签 x。

但这项线性论证只解决外层 Adams 源替换。仍须证明递归给到 x1 的是外层需要的 **第零层 h 关系**，或把递归的全部 λ 层与商统一后直接证明联合 GL。递归返回值未携带 k、截断长度或实际代表，无法从函数签名独立读取这张证书。

同理，第二个 GL 调用的输入 dx 可换成 dx+B_(b−1)，正好符合 d_b 目标不定性；仍须实际有限商连接关系相容，不能只把两个孤立等式拼成严格同伦方框。

## 5. 两类“缺条件”其实可以从正确证书推出

以下是本轮进一步收窄，避免把可证推论错列成新公理。

### 非负 k 与正 n1

实际配置每条三角 Σd=1 或 2，故 `d_f+d_g+e_h≤2`。M1 的 c 是实际非零 Adams 边界长度，c≥2，因此 `k=c−d_f−d_g−e_h≥0`。不必另加运行时 assert。

若 bary≠0，则 barx=g_E2(v)，v∈Z_(c−1)，且 `d_c barx=g_E2(d_c v)=g_E2 f_E2(x)=0`，从自然性得 barx∈Z_c。因 d_a barx 非零，a>c，故 `n1=a−c+d_f−e_f≥1`。前提是谱页状态正确、复合 g_E2 f_E2=0；零输出时 dxtop=0 可能仅记录存活下界，不能套严格 a>c。

此 n1 证明针对 M1，不能无条件套给异常 M0：例如 d_h=2,d_g=0,a=2 时 raw n=0。若只是零/inessential synthetic 关系，不一定产生有意义的隐藏输出。全量证书须对这种低长度路径证明它不写入非零新结论，或逐成功调用核查 n1≥1；不能声称配置本身已排除它。后文窗口界以实际有效正长度关系 M≥e_f+1 为前提。

### GL 首次长度界

外层输入 d_b x=dx≠0。若核心 MH2 已正确用于 x1∈x+Z_b，则核心 cycle 结论给 x1∈Z_Q，Q=n+d_g+e_h。因 d_b x1 非零，必有 Q≤b−1，于是

```
n≤b−1−d_g−e_h = b−2+e_f−m1 ≤ b−2+e_f.
```

这就是经典 GL 要求的首次延拓长度上界。单看 line583 的状态不等式只能得到 n+d_g<b，少一个 e_h；核心的 cycle 结论排除临界情形。因此这项算术界是递归正确性与源 coset 同步的推论，不是额外独立缺假设。

## 6. crossing 与 error12：已经能证明什么、仍缺什么

675–707 检查当前 f 的更高滤过源。M1 本层 MH2 需要的 h 无 crossing 由递归 prev 调用承担，不是本层循环直接认证。

有限源 level=10000−b 时循环跳过更低 level 的源，即已知 Z_b 部分。联合 coset 定理允许在源加 Z_b，这为跳过提供合理数学方向。但“加 Z_b 不改 d_b”只证明 Adams 页线性事实，尚不足以证明每个 λ^A Z_b 的 f-像都是允许的短 ESS 边界，或能同步选择同一方框代表。因此应补证明：

**C-cycle：** 被跳过的 Z_b 方向所产生全部可能 crossing，只改变所选源 coset/允许短 ESS 边界，不能改变最终要写入的 d_(b+l−m) 目标 coset。

错误12只发生于 M0：算法挑出的 h_E2 前像状态 `level_barx≤level_x`，然后 crossing 枚举把该错误当作“无须阻断”。一条可证的条件性解释是：

**C-image：** 在共同有限商 Q_N 中，若该前像可实现为 a，且 hhat_N(a) 是当前源 λ 层的代表，则 fhat_N hhat_N(a)=0；它不可能支持相关非零 essential f-ESS 微分。

M0 最小 h、且共同 Q_N 不超过该前像已知存活长度时，E2 自然性可把此解释落实。一般正 k、跨商或递归情形仍需前像提升及标签对应；“算法选择的前像 level 未通过”本身不证明不存在任何 relevant essential crossing。

因此需要的是 C-cycle 与 C-image/搜索完备性引理；未构造源码反例，也未证明它们对所有历史状态成立。不能把 error12 字面当作算法错误；同样不能把忽略它当作已证排除定理。

## 7. 程序整体足够的精确证书版本

对每个实际成功写入，取完整调用树，递归节点应给：

1. 所有实际对象、f/g/h normalized map 及 filtration，实现 E2 矩阵的数据对应；
2. 每个 Adams d_a 的源/目标 coset 与已证状态；
3. 每个节点的 (n,m,l,k,m1,a,Q,r')，以及强 Q_a 带层 May 关系，而非仅投影后的弱关系；
4. 子节点 h 输出与父节点所需 h 输入之间的源 coset 同步和第零层/共同 λ 层转换；
5. g 输入的所需 cycle 资格（特别 m1=1 的 Z2）及实际代表；
6. C-cycle、C-image 和 crossing 枚举完整性；
7. 两个 GL 调用能放进同一个实际有限商方框，源 coset 允许 x→x+Z_b、边界 coset允许 dx→dx+B_(b−1)，输出目标按实际 cutoff取商；
8. 若结果是 SynCs 而非新 Adams 微分，另给 May 所选具体源代表向完整 νX 的提升/连接障碍消失，才能推出经典延拓和目标永久性。

在这些证书下，核心 MH2、有限商自然性、实际 May 方框/GL、经典解码可递归推出每个成功写入。这里列的是一个明确充分方案，不宣称条件最小，也不把整张证书作为新增 Lean 公共接口。

### 可替代“逐层恢复第零层 h”的更小整体契约

对有限源一次最终写入，设原数据 `d_b x=dx`，两个求像长度为 m、l，欲写 `d_R y=z`，其中 `R=b+l−m`。可直接在自然有限商方框中给证书，不必先把每个递归节点都包装成旧的固定标签 MH2。

取整数 A,B>0 与共同输入层 j≥0，令 `Q_T W=νW/λ^T`，使用标准商三角的连接

```
δ_W : Q_A W → Σ^(1,−A) Q_B W,
Q_(A+B) W → Q_A W → Σ^(1,−A) Q_B W.
```

要求有同一组实际代表 α、β，使得

```
α ∈ π(Q_A X) 检测 λ^j x'，x'∈x+Z_b；
β=fhat_A(α) 检测 λ^u y，u=j+m−e_f；
δ_Y(β)=fhat_B(δ_X(α)) 检测 λ^v z，
v=j+b+l−A−1−e_f；
0≤u<A，0≤v<B。
```

“检测”包括实际 leading filtration、所需标签存活与目标 coset；不能只指某个零关联分次等式。连接微分解码给

```
R=A+1+v−u=b+l−m,
d_R y=z
```

（按该目标的 Adams/短 ESS 不定性解释）。δ_X(α) 与第二个调用的源 dx 也须同步到同一实际代表，允许 dx+B_(b−1)。完整调用树给出这些相容代表及正确 leading 检测，便已经足够；**不必独立证明“所有递归输出都恢复旧第零层固定 x 的 h 关系”**。后者只是一种可行但更强的模块化认证路线。

相容证书中的 δ/映射等式由同一自然方框自动交换；需要证明的是程序选择的 E2 向量和 kernel/crossing 处理确实允许选到同一 α、β，并保证所声称的 leading 检测。共同正层定理不是唯一方案；有了上述证书无需取消 λ，也无需把所有中间输出转成同一形式的纸面 MH2。

因此当前最小的**责任分类**（不是已证明数学必要充分的最小前提）可收为三项：

- **R-representatives：** 从成功调用树提取共同商/λ层、source coset 与相容实际代表，证明 leading 检测及必要 cycle（特别 m1=1 的 Z2）。MH2 核心已提供其中的局部几何构造。
- **R-search：** 证明跳过 Z_b、忽略错误12及矩阵 kernel 检查足以排除会改变最终目标 coset 的 crossing，或直接证明其影响被 R-representatives 的允许不定性吸收。
- **R-classical：** 仅对 SynCs 等经典写入，补具体 May 源向完整 ν 的提升及 λ反演后的经典解码。

第5节的 k≥0、n1≥1、GL 首次长度界属于正确状态与前两项证书的推论，不再列为独立缺前提。对只声称最终 Adams 微分的流程，不必额外承担 R-classical；对所有计算输出则必须覆盖。

### 从强证书自动确定的 native 商与右连接 crossing 窗口

为与 GL 并行复核统一记号，令首次返回长度 M=n、内部 MH2 微分长度 R=a、h 长度 L=l、g实际AF=d_g。强商本来就是

```
N=R=M+d_g+L, K=L−e_h,
Q=N−K=M+d_g+e_h,
A=M−e_f+K=N−1−m1.
```

`Q≤b−1` 已在第5节由非零 d_b 与核心 cycle 结论推出，故
`N≤b+K−1`，连接 δ_N 上原源的边界标签 offset 为
`D=b−N−1+K=b−Q−1≥0`。首个 f 关系的源 offset K、目标 offset A 都在 native Q_N 内；无需猜截断参数，也无需先投影到会丢失目标的 Q_Q。

目标 λ^A y 的右连接 crossing 若来自更高源偏移 a'>0，有限商的条带资格要求 `A+a'<N`，故 `a'≤m1`（若又乘共同层 Δ，则 a'≤m1−Δ）。代码 `GetCrossR(..., M−d_f+2)` 扫描 `1≤a'≤M−d_f`。实际配置的 excess 总和至多1，而非零隐藏输出的正长度资格 M≥e_f+1，给

```
M−d_f ≥ 1−(d_f−e_f) ≥ d_g−e_g=m1.
```

因此该循环的**滤过偏移窗口足够覆盖右连接的全部可见 crossing**。不能再笼统说这里缺“扫得够不够远”或“商怎么选”。还需认证的是：程序 staircase 候选与相关 ESS 定义域/leading 标签的对应、筛掉 Z_b 与 error12 的合法性、两次调用在上述确定商中的相容代表。窗口算术本身已由强证书确定。

## 8. 王老师修改稿的覆盖边界

| 实际需要 | 4/24 核心能否给 |
|---|---|
| D 映射自然性 | 不属于 MH2；可用独立自然性 |
| M0、h/g 最小过滤、k=m1=0 | 可以，给真实第零层关系 |
| M0、正 k，且 h/g 第零层前提已认证 | 可以给强 Q_a 带层关系；不能取消 λ |
| M0、正 m1 | 条件性可以；先提供 y∈Z_(m1+1) 和 g 实际关系 |
| M1 固定 x 输出 | 未直接覆盖；源码只确认源 coset |
| M1 source-coset 联合 GL | 核心可作局部几何部件；仍需递归代表/共同商层的粘合定理 |
| 跳过 Z_b、忽略错误12 | 原稿一般无 crossing 假设不等于算法搜索完备性；需上述引理 |
| SynCs 经典写入 | 有限商核心不足，需具体源提升及经典解码 |
| 4/25 共同正输入 j | 字面版本已有截断反例；不能未经修复用作递归桥梁 |

最终结论：SS 全部相关计算依赖一个“按调用树、容许 Adams 源 coset、保留有限商 λ 层并兼容 GL”的定理族。它严格大于 Main 的一个 (3,0,0,8,134) 数值特例，也不能简化成配置中的 175 个零层方向。当前已证核心是该定理族的重要局部部件；实际全部成功日志是否提供其剩余证书仍须调用树或历史状态，不能由最终数据库和分支计数替代。

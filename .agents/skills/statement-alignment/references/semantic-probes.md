# 语义探针

按当前疑点选择探针；不要求对每个声明穷举本表。探针要留在全部真实前提和固定对象范围内。

## 量词、参数和实例

- 写清见证依赖：`∃ C, ∀ x, bound C x` 强于 `∀ x, ∃ C, bound C x`。一个有限例子不能代表无限族。
- 从实际声明展开 section 参数与类型类，不能把文件周围的假设自动算入声明。检查是否偷偷增加紧致、完备、有限维等强条件。
- 固定模型上的定理，与对任意具有少量字段的抽象模型成立，是不同命题。反例需要说明能否实现为声明使用的那个对象，并满足其全部约束。

## 定义和表示

- 追踪别名、结构字段和所选映射，问调用者提供什么、结论实际构造什么。`theorem t (h : P) : P := h` 合法，但不能作为从原始假设产生 `P` 的证明。
- 证书或结构字段包含结果并非自动错误；检查是否有从原始输入产生该字段的构造。项目已登记的上游未完成构造应标为待补责任，不能直接判成额外调用者假设。
- 有限代理、坐标模型、商关系、任意线性同构或重新标定的类，需要到论文对象的正确桥接。核对桥接方向、自然性、与乘法/移位的相容性；只证明载体同构未必足够。
- `True`、空集、空结构或 `Subsingleton` 可能合法；只有相对来源丢失了必要内容时才构成对齐问题。

## Kervaire 项目中的高价值核对

- 检查实际 `Standard.model`、球对象、标准 `hᵢ` 及其平方、ν/λ 映射与选定同构的关联，不能用同名抽象数据替代。
- 分清页码、`(s,t)`、stem `t-s`、合成权重、移位和重分次；检查微分、边界、代表、存活、永久循环、非零性及检测之间实际证明了哪种结论。
- 同页检测相同可能只给“差落入更高滤过”；不能直接当作实际同伦类相等。有限商中的结论也不能直接提升为完整对象结论。
- 几何维数公式中的自然数减法、正索引条件与零维边界需要分别核对；沿用当前目标和源码约定，不能仅凭标题推断。

## 区分实例和证据强度

可用零、单位、空/单点域、端点、退化维数、非单射映射等区分候选解释。Lean 的零除法、自然数截断减法和空集上上/下确界等采用库的全定义约定，先读固定版本实现。

抽象反模型、固定对象上的数学反例、Lean 已验证的反例分别标明。数值或有限样本只支持其实际覆盖范围；没找到反例不是等价证明。编译日志记录精确输入、命令、返回结果及未闭合依赖，不把 `#print axioms` 当作语义对齐证明。

发现歧义时保留不同读法及其后果。发现差异时给出两侧精确命题和证据，不静默加强前提或弱化结论。冻结接口的处理以仓库当前规则为准。

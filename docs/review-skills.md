## 上游内容审查与取舍

| 原有指导 | 本项目处理及原因 |
| --- | --- |
| 完整声明回译、量词/隐式前提/定义展开、表示桥接 | 保留；这是对齐检查的核心，不能只比较名称或注释。 |
| 独立回译者与比较者 | 按任务需要使用；同会话分步不冒称独立，不强制额外 agent、模型或调度任务。 |
| Horizon mission / roadmap / PR revision 与修复流程 | 改成实际提交及未提交输入、AimPaper、Blueprint、现有修正与接口提案；不引入 Forge、队列或新的门禁。 |
| 依赖 proof-review / lean-search / lean-refactor | 删除未安装依赖；使用现有本地源码、工具链、项目审计和可用工具。两个本地 skill 只在问题需要时互相引用。 |
| 代理对象与证书字段审查 | 保留，但区分真正的调用者附加假设与已登记的上游构造/证明责任，不能把后一类转给下游。 |
| 定义的真实消费者与最小替代实验 | 保留；区分定义相等、桥接不足、实例冲突、语义错误及可选工程改进。 |
| 后处理发现低成本 API 改进应修复或解释 | 不作为本项目强制要求；先给证据和迁移代价，冻结接口改动遵守已有授权。 |
| 原文/图对应与完成状态 | 遵守项目八模块实际归属及公开绑定；网页状态、源码阅读、局部编译和传递信任审计分别报告。 |

## 项目中特别需要防止的误判

- 抽象比较族缺少相容性字段，不足以反驳固定 `Standard.model` 上需要另证的性质。现有首商相容性提案中的证据等级与固定对象区分，说明这里必须核对真实背景和全部前提。
- Geometry 的局部推导可已完成而继承 Literature 的未完成责任；不能据此把几何陈述判为不对齐，也不能把局部证明完成写成整个依赖闭包已闭合。
- 不能把已批准修正版与原文的差异重新当成未经授权的漂移；也不能拿未获批准的较弱 Blueprint 自行证明修改合理。
- 不因命名空间仍含 `Computation` 就使用已删除的旧导入路径或改变责任归属。

## 输出与持久化

普通检查直接在回复中交付，说明范围、证据与局限。确需维护接口问题时，按 [接口提案指南](interface-proposals.md) 更新原提案或建立责任模块草稿；独立性与人审状态必须真实。论文修正仍只在 `corrections.yaml` 维护，数学正文与来源仍在 Blueprint。该说明不是新的审查报告库、数学契约或修正记录。

新增文件不改变现有授权，不增加跨模块编辑、公共接口重构、证明洞、依赖升级或网站发布权限。保持接口的证明工作按原规则继续，不为可选工程建议增加全项目暂停流程。

来源、许可证及改编声明分别随两个 skill 保存于 `references/sources.md`。维护本地 skill 时只更新本项目版本；上游更新需重新比较，不能覆盖这些适配规则。

## Proof of the d6 exclusion

The C2 E2 source at `(6,133)` has basis `v=(x126,6)[1]`, `w=i x127,6`.
Under the top-cell map, `q(v)=x126,6` and `q(w)=0`. The established sphere
disjunction has `d3(x126,6)=A` or `A+D`, both nonzero. Therefore every
source vector with v coefficient one has nonzero d3. In particular, the
E6 source is a quotient of the line represented by w; a combination with
v cannot provide a separate E6 class.

If `d5(x)=T`, ordinary bottom-cell naturality gives

```
d5(w) = i(T) != 0 on E5(C2).
```

Then w cannot represent an E6 source. If `d5(x)=0`, x supplies an E6
preimage of w. If x had been an earlier boundary, its image w would also
have been an earlier boundary, which only makes the conclusion immediate.

For every sphere E2 class at `(12,138)`, its bottom image belongs to the
span of C2 target coordinates e2 and e3 from the Round 1 target table.
Those coordinates are d2 and d3 boundaries, respectively. Thus the bottom
map on this target bidegree is already zero on E4, and hence on E6.
Ordinary naturality consequently gives

```
d6(w) = i(d6(x)) = 0.
```

This exhausts the E6 source. No higher-map comparison, choice of a
homotopy lift, or generalized Leibniz/Mahowald premise is needed here.
The independent auditor checked the E5 quotient and this argument in
Round 2; the sphere target-line calculation and exclusion of the v
component are made explicit above.

## Exact finite Moore relation for the remaining d5

Use the actual synthetic Moore triangle

```
Sigma^(0,1) S --tilde2--> S --i--> M=nu(C2) --> Sigma^(1,1) S,
lambda * tilde2 = 2,   tilde2 mod lambda = h0.
```

Let `A=x127,7,2` in `pi_(127,134)(S/lambda)` and let
`D=partial_lambda(A)` in `pi_(126,135)(S)`. This is a fixed actual
Bockstein boundary, with `lambda D=0`. The known first Bockstein gives

```
rho(D) = d2(A) = h0 b,      b=x126,8 in Ext^(8,134)(S).
```

For `N>=1`, exactness of the lambda^N cofiber sequence and the Moore
triangle after tensoring with `S/lambda^N` yields

```
i(D) is lambda^N-divisible
  iff rho_N(i(D))=0
  iff there exists beta_N in pi_(126,134)(S/lambda^N)
       with tilde2 beta_N = rho_N(D).
```

The Bockstein lifting criterion says that the original a=i(A) has zero
outgoing differentials through d_(N+1) exactly when i(D) is
lambda^N-divisible. Thus the known survival of a to E5 supplies beta_3.
The additional assertion `d5(a)=0` is equivalent to the existence of
beta_4 satisfying the displayed **same-D** equation. The independent
auditor checked these page indices and exactness (Round 2 audit section 8,
PASS). Existence of some compatible beta_4 is sufficient; this does not
assert that every previously chosen beta_3 lifts. This is a criterion for
outgoing survival; nonzero E5 status follows separately from the incoming
source calculation above.

The possible leading reductions of beta_3 or beta_4 can be determined
without guessing a Toda bracket. The raw b supports

```
d3(b) = c = h1 x124,10,2 in Ext^(11,136)(S).
```

Write `B=x126,8,4+x126,8` and `H=h6(C'+X2)`. Both B and H have recorded
zero outgoing differentials through d5, in both archives. Direct normal
forms show `h0 B=h0 b` and `h0 H=0`. Exhaustive linear algebra in the
six-dimensional group `(8,134)` shows that the leading reductions that
satisfy the **exact E2 equation** `h0 rho(beta_N)=h0 b` and have zero
outgoing d2,d3,d4 are precisely B and B+H. The boundary direction
`h0^6 h6^2` cannot be added here because its h0 product is nonzero in E2.
This classification concerns leading reductions only; lambda-divisible
changes of beta_N remain and are not discarded.

There is an explicit cofiber representative for the correction of b:

```
q(C2 gen338) = x126,8,4 + H,
q(h6 * C2 gen70) = H,
q(C2 gen338 + h6 * C2 gen70) = x126,8,4.

The first C2 class has d3 equal to `x124,10,2` times the eta-extension

correction cancels precisely the d3 of b and leads to B. It identifies

The obstruction for a specified beta_3 to lift through

```

The vector `q(z)=h0 h6 x62,10+h0^4 x125,8` lies in this exact group.

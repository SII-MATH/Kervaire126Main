## Result

Work with the 2-complete sphere and the ordinary mod-2 Moore spectrum
`C2=cofib(2:S->S)`. Let `u=h7[0]` be the bottom-image class in
`E2^(1,128)(C2)`. With the already established nonzero permanence of `h6^2`,
the following are equivalent:

1. u is a nonzero permanent cycle.
2. There is a class theta in `pi_126(S)` detected by `h6^2` with `2 theta=0`.

The negative implication was proved in the first round. The argument below
supplies the previously missing positive implication. It does not determine
whether u is permanent, or any unresolved differential on it.

The proof constructs an order-two theta directly. It does not require a
claim that the top-cell image of every independently chosen lift of u has
one specified representative.

## Source Theorems and Conventions

Use synthetic bidegrees `(stem,weight)`, so an Adams class in `(s,t)` lies
in synthetic degree `(t-s,t)`. Suspension in the synthetic stable category
has degree `(1,0)`, and lambda has degree `(0,-1)`.

Let `Ssyn=nu(S_2^complete)` and `M=nu(C2)`. The mod-2 homology sequence

```
0 -> H_*(S) -> H_*(C2) -> H_*(Sigma S) -> 0
```

is short exact. The synthetic cofiber-preservation theorem gives

\[
 \Sigma^{0,1}S_{\rm syn}
   \xrightarrow{\widetilde 2} S_{\rm syn}
   \xrightarrow{i} M
   \longrightarrow \Sigma^{1,1}S_{\rm syn}.
\]

Here `lambda * tilde2 = 2`, and reduction of tilde2 modulo lambda is h0.
The first identity follows from the assembly square for the filtration-one
factorization of the actual degree-two map. The second identifies the
boundary of the nonsplit Steenrod-module extension for C2 with h0.

## Positive Implication

Write `rho` for reduction modulo lambda. The lambda cofiber sequence gives
the natural connecting homomorphism

\[
 \partial_\lambda:\pi_{k,w}(X/\lambda)
          \longrightarrow\pi_{k-1,w+1}X,
 \qquad \lambda\partial_\lambda=0.
\]

Let `h=h7` in `pi_(127,128)(Ssyn/lambda)`. The known Hopf-invariant
differential and the Bockstein comparison give

\[
 \rho(\partial_\lambda h)=d_2(h_7)=h_0h_6^2\ne0
       \quad\text{in } E_2^{3,129}(S).
\]

Assume u is permanent. By BHS Theorem 9.19, it admits a lift in
`pi_(127,128) M`. Hence `partial_lambda u=0`. Since `u=i(h)`, naturality
implies

\[
       i(\partial_\lambda h)=0.
\]

Exactness of the actual synthetic Moore triangle therefore supplies

\[
 x\in\pi_{126,128}S_{\rm syn},\qquad
       \widetilde2 x=\partial_\lambda h.
\]

Multiplying by lambda proves

\[
       2x=\lambda\widetilde2 x
          =\lambda\partial_\lambda h=0.
\]

Reduction modulo lambda gives

\[
       h_0\rho(x)=h_0h_6^2.
\]

The source `E2^(2,128)(S)` is one-dimensional, generated by h6 squared,
and its product with h0 is nonzero. Thus `rho(x)=h6^2`. By its known
nonzero permanence and the detection part of BHS Theorem 9.19, lambda
inversion sends x to a nonzero class theta detected by h6 squared.
It preserves the equation `2x=0`, so `2 theta=0` as required.

Signs in the connecting-map convention do not change the argument: the
reduction is over F2, and multiplication by lambda still annihilates the
boundary class.

## Reverse Implication

The actual Moore long exact sequence gives `im(q)=ker(2)` for
`q:pi_127(C2)->pi_126(S)`. If theta is order two, choose a with q(a)=theta.
The map q preserves Adams filtration, so a cannot lie in F3 since theta
has exact filtration 2.

In C2 stem 127, the E2 groups in filtrations 0 and 2 vanish; filtration 1
has sole generator u. Strong convergence forces a to be detected by u.
There are no incoming differentials on u because their source filtration
would be `1-r<0`. Thus u is a nonzero permanent cycle.

## Implications and Boundaries

Together with the first-round vanishing bound, this identifies the exact
finite target: an order-two theta6 exists if and only if all actual outgoing
`d_r(u)` for `2<=r<=62` vanish. The older cw210 archive records the cases
through d10; the latest cw49 only records the cases through d6. A bounded
target computation separately excludes d9, but the current comparison does
not independently resolve d7, d8, or d10. These archival survival ranges
must not be silently interchanged. No outgoing differential is decided by
the equivalence itself.

The initial search considered Ma's corrected geometric boundary theorem.
Ma Theorem 5 requires a specified higher lift; permanence of the projected
class alone cannot simply replace that hypothesis. The proof above instead
uses the actual synthetic Moore triangle and the full BHS lifting theorem,
so no application of the older five-case Behrens statement is assumed.

This removes the positive-implication gap in the first-round report. It
does not compute d11 or certify its proposed target as nonzero on E11.
The current production Lean object family has no named C2 object, so this
report does not claim delivery within an existing C2 formalization interface.
